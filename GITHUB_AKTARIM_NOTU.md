# GitHub Aktarim Notu

GitHub hesap/depo linkleri:

- Hesap acma: https://github.com/signup
- Yeni depo olusturma: https://github.com/new
- GitHub Desktop indirme: https://desktop.github.com/

## Onerilen Yol

1. GitHub hesabi ac.
2. GitHub Desktop indir ve kur.
3. GitHub Desktop ile giris yap.
4. `deneme` klasorunu repository olarak ekle.
5. Repository adini ornegin `coffee-clicker` yap.
6. Depoyu `Private` olarak olustur.
7. Ilk commit mesajini `Initial Unity prototype` yap.
8. `Publish repository` ile GitHub'a gonder.
