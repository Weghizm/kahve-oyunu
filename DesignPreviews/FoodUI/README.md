# Food UI Design Previews

These files are design references and are not imported by Unity.

- `food-mobile-three-column-preview.png`: Approved direction for the mobile three-column category layout.
- `food-locked-card-compact-preview.png`: Approved compact locked-card hierarchy.
- `food-coffee-card-rich-preview.png`: Rich unlocked coffee-card composition reference.
- `food-panel-polished-reference.png`: Overall quality, palette, spacing, and panel-finish reference.

Implementation remains modular: product art, text, badges, strips, and buttons are separate runtime UI elements.
